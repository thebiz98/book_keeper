## 5. Schema and contract delta
- Schema v2: `CHECK(units_per_bundle > 1)` (LLD 5.3); optionally `UNIQUE(item_id, lower(bundle_name))`; bundle barcode uniqueness enforced in service (or unique partial index across a view); remove `bundle_id`/`bundle_quantity` from bill-line tables, add `pack_label`/`pack_quantity` (FR-02).
- IPC: add `update_bundle`, `delete_bundle` (main.rs, controller, service trait + impl, `ipc.ts`, `ApiClient`, mock); consider `get_item_bundles(item_id)` for the Inventory sub-table; `get_bundle_suggestions` should return exact multiplier and read-only.
- DTOs: `UpdateBundlePayload`; unify `defaultBundlePrice`/`bundlePrice`; `CreateBundlePayload.item_id` should be required (not `Option`) in the contract.
- UI: BundleCreationModal combobox, `onBundleCreated(bundle)` returning full data, Alt+B handlers.
