## 5. Schema and contract delta
- Contract: `InventoryAllocationStrategy` gains `reverse_sale_allocations`, `deplete_lots_for_outflow` (known) and, for WA readiness, `stock_valuation(uow, item_id)`. `PurchaseRepository`: add `find_item_by_id`, remove FIFO-named duplicates and stub defaults. `ReportRepository`: implement and use.
- AppState: factory `build_strategy(AllocationMethod)`; `build_app_state_with(pool, strategy)` for tests; inject ItemService/AccountingService where LLD says (or amend the LLD).
- Schema (only if WA must avoid per-lot rows): `purchase_item_id` nullable on allocation tables (or the DD-11 `STOCK_OUTFLOW_ALLOCATION`), optional `items.avg_cost`. LIFO needs no schema change. DD-11 table is already required by other reviews.
