## 5. Schema and contract delta
- `sale_stock_allocations.returned_quantity REAL NOT NULL DEFAULT 0` with CHECK `0 <= returned_quantity <= quantity_depleted`.
- Replace `adjustment_stock_allocations` with `stock_outflow_allocations(id, source_type, source_id, purchase_item_id, quantity_depleted, unit_cost)`. CHECK `source_type IN ('ADJUSTMENT','REPLACEMENT','VENDOR_RETURN')`.
- `purchase_transactions.source` (`PURCHASE|ADJUSTMENT|OPENING|RETURN`); `purchase_items` CHECKs; `return_items.cost_amount` and `line_type`.
- Rust: `SaleStockAllocation.returned_quantity`; `StockOutflowAllocation` entity; strategy trait with `reverse_sale_allocations(sale_item_id, qty, restock) -> Reversal`, `deplete_lots_for_outflow(...)`, `PurchaseRepository::find_lot_by_id`, allocation repo `find_open_by_sale_item_id` (depleted > returned, ORDER BY id DESC).
- IPC/DTO: `get_item_lots(item_id)`; add `returned_quantity` to the `StockLot` DTO/TS type; `PnLReport` gets `sales_returns`, `net_sales`, `gross_profit`, `inventory_losses`.
- Mock: lot ledger and allocation emulation.
