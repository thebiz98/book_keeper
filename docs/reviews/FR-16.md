## 5. Schema and contract delta
- No column changes needed. Optional: `CHECK(mrp IS NULL OR mrp > 0)` on both tables via the v2 migration, after cleaning legacy zeros.
- New: a shared Rust `validate_mrp(Option<f64>)` helper used by create_item, update_item, create_bundle, nested bundles and import.
- UI contract: the sale indicator and F4 lookup need `mrp` from `ItemSearchResult` and `ItemBundleSearchResult`. Both already carry it.
- `UpdateItemPayload.mrp`: null must mean clear. Document it, and have the TS type and mock honour it.
