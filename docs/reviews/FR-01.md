## 5. Schema and contract delta
- `purchase_transactions`: add `source` (PURCHASE|ADJUSTMENT|OPENING|RETURN, default PURCHASE, CHECK), `supplier_invoice_ref` TEXT NULL; header invariants maintained from ledger.
- `purchase_items`: drop `bundle_id` (+FK) and `bundle_quantity`; add `pack_label` TEXT NULL, `pack_quantity` REAL NULL.
- `payment_settlements`: add `kind` (UPFRONT|SETTLEMENT|RETURN_CREDIT|REFUND_OUT|REFUND_IN), `return_id` NULL, make `transaction_id` nullable.
- `CreatePurchasePayload`: add `payment_status`, `supplier_invoice_ref`; remove client-controlled `transaction_code`; item payload keeps `bundle_id` (write-time only) and quantity/cost per selected unit.
- New `PurchaseHistoryRow` DTO (party name, line count, supplier ref, source filtered); `PurchaseHistoryFilter` add `search_query`; default ordering date desc.
- `PurchaseItemDetail`: add remaining quantity display, pack label snapshot; `PurchaseDetailView.settlements` with `kind`.
- Per-source code sequences (PUR/ADJ/OPN/RTL) generated inside the tx; error contract `AppError {type, details}` on all four commands.
- Mock client and TS types updated in lock-step (camelCase `supplierInvoiceRef`, `paymentStatus`, `packLabel`, `packQuantity`, `source`).
