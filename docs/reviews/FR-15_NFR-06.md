## 5. Schema and contract delta
No schema change. Contract: `createSale` must carry the dialog's `paid_amount`, `payment_status`, `party_id` and return `SaleSummaryResponse` (code, total, paid, balance_due) to feed the result view (HLD §9.3; FR-02 F-01/F-09). UI additions: `HOTKEYS` registry module, `PaymentDialog` result mode, `PartySelector.onCreateNew`, `Modal` focus-trap/return and ref-stable handlers, Search `onEnterEmpty`.
