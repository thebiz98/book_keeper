# FR-05 Review: Real-Time Low Stock Monitoring

Aligned rule: universal, strict `current_stock < 5` (base units); `is_low_stock` is a cache flag recomputed on every stock mutation; dashboard widget = `get_low_stock_alerts` ordered `current_stock ASC`; inventory filter `show_low_stock_only`; `[Inward (F3)]` row action pre-fills the purchase page. Earlier reports (FR-01..FR-07) already cover hard-coded `< 5.0` literals, incremental cache + `.max(0.0)` clamp, vendor-return-without-lot cache/lot drift. Referenced here, not repeated.

- IPC: no new command; purchase-page pre-fill is frontend state (store field) only.
